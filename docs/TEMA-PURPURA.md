# Identidade visual púrpura e preto — Terrania

A identidade do **site** usa preto `#0b0812`, superfícies púrpura muito escuras `#191021` e destaque violeta `#b986ff`. Texto principal `#f3edfa` e secundário `#b7a9c8`.

Todas as páginas institucionais compartilham a mesma paleta, incluindo navegação mobile, botões, foco, formulários, guia, rodapé, página 404 e cor da barra do navegador. O escudo SVG também usa púrpura.

**Escopo:** nenhuma cor do cenário do jogo, sprites, HUD Canvas, física, combate ou multiplayer foi alterada. As imagens do mundo continuam representando as cores reais do jogo.

Validação: `npm ci && npm run typecheck && npm test && npm run build`; conferir cabeçalho, contraste, menus e ações em desktop/mobile.
